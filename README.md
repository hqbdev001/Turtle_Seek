# Turtle Finding Mini Game

Unity와 C#으로 제작한 간단한 **거북이 찾기 미니게임**입니다. 화면에 배치된 거북이 중 목표 거북이를 제한 시간 안에 찾아 클릭하는 게임입니다.

아내의 아이디어를 구현해주었습니다.

## 주요 기능

* **게임 진행 관리:** 준비 → 거북이 표시 → 정답 선택 → 결과 표시
* **무작위 배치:** 거북이 이미지와 위치·크기를 섞어 배치
* **시간 제어:** 코루틴을 이용한 카운트다운 및 거북이 페이드아웃
* **선택 판정:** 거북이 클릭 이벤트를 받아 정답 여부 판정
* **설정 분리:** 거북이 수, 표시 시간, 정답 선택 시간 등을 인스펙터에서 조정

## 코드 구성

|파일|역할|
|-|-|
|`PrtMain.cs`|게임 상태 전환, UI, 타이머, 정답 판정|
|`PrtTurtle.cs`|개별 거북이의 표시·위치·크기 및 클릭 처리|
|`PrtIngameSettings.cs`|게임 진행에 필요한 설정값 관리|

## 개발 정보

* **엔진 / 언어:** Unity / C#
* **형태:** 부부 공동 제작 소형 프로젝트
* **순수 코딩 시간:** 약 1\~2시간 (프로젝트 설정 및 프리팹 작업 제외)
